Scan your whole machine instead

The page only sees what you paste. The CLI also checks logged-in cloud CLIs, publish tokens, SSH keys, the Docker socket, sudo, mounted shares, cloud-synced folders and secret-looking env vars. It's read-only and never prints secret values.
